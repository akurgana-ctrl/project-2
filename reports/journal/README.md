# יומן כוח התערבות

יומן עבודה מתמשך של כוח התערבות בלבד (לא עניינים אישיים).
כל פריט נכנס בהקלדה קולית או בטקסט חופשי, ו-Claude מסווג אותו, משייך לפרק, ושומר כאן.

## פרקים
| פרק | קובץ | סטטוס |
|---|---|---|
| לעילוי נשמת שפי פז – פרק האקטיביזם | [`chapters/shefi-paz.md`](chapters/shefi-paz.md) | פעיל |

## סוגי פריטים
| סמל | סוג | מתי |
|---|---|---|
| ☐ / ☑ | משימה | משהו שצריך לעשות (פתוח / נסגר) |
| 🧠 | זיכרון | עובדה, תובנה, משהו שנאמר ושווה לזכור |
| ⚖️ | החלטה | משהו שהוחלט – מי החליט ומתי |
| 👤 | איש קשר | אדם חדש ותפקידו בפרק |
| 💡 | רעיון | רעיון שעוד לא הפך למשימה |

## פקודות קוליות
| אומרים | מה קורה |
|---|---|
| `יומן: …` | פריט חדש. Claude מזהה לבד את הסוג ואת הפרק |
| `יומן שפי: …` | פריט חדש ישירות לפרק של שפי פז |
| `פרק חדש: …` | פתיחת פרק חדש ביומן |
| `סגור משימה: …` | סימון משימה כבוצעה, עם תאריך סגירה |
| `מה פתוח ביומן?` / `מה פתוח בפרק שפי?` | כל המשימות הפתוחות, לפי ותק |
| `מה אני זוכר על …?` | חיפוש בזיכרונות ובהחלטות |

> ⚠️ הריפו ציבורי: לא להכניס כאן מידע רגיש (טלפונים, כספים, פרטים אישיים של משפחות).
