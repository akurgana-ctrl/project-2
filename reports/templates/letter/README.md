# תבנית מכתב / נייר עמדה – כח התערבות

משוחזרת מנייר העמדה הרשמי (Word, ספטמבר 2026). כל מכתב רשמי של הארגון ייבנה לפיה.

## מפרט
- A4. שוליים: ימין 50pt, שמאל 45pt, עליון 140pt, תחתון 42pt.
- כותרת עליונה: הלוגו (`logo.png`) ממורכז, 125×105pt, במרחק 9pt מראש העמוד, בכל עמוד.
- גופן **David** בגודל 12, בכל הטקסט. מרווח שורות קבוע 17.7pt, ו-10pt אחרי כל פסקה.
- סדר העמוד:
  1. תאריך עברי ותחתיו תאריך לועזי, מיושרים לשמאל.
  2. **לכבוד:** (מודגש), ומתחתיו הנמענים, כל נמען בשורה.
  3. **הנדון: …** מודגש, עם קו תחתון, ממורכז. מתחתיו כותרת משנה מודגשת וממורכזת.
  4. סעיפים עם כותרות "א. …", "ב. …", מודגשות ועם קו תחתון. פסקאות ממוספרות 1, 2, 3 ברצף לאורך כל המסמך, ביישור לשני הצדדים. רשימה פנימית (א., ב., …) מוזחת 36pt מימין.
  5. חתימה ממורכזת: **בברכה,** / שם, תפקיד / כח התערבות.
- כתיב שם הארגון: **כח התערבות**.
- חותם ברירת מחדל: אדם קורגן, מנכ"ל.

## שימוש
```
python3 build_letter.py content.json logo.png out.docx
soffice --headless --convert-to pdf out.docx
```
`content.json` מכיל את השדות: date_hebrew, date_gregorian, to[], subject, subtitle, sections[{title, paragraphs[]}], signer, org.
להכנסת טקסט ארוך לעמוד אחד: `"layout": {"size": 10.5, "pitch": 13.0, "gap": 0.3, "top": 116, "sig_gap": 22}` (sig_gap = רווח לפני החתימה). בלי השדה הזה המסמך נבנה במידות התבנית המקורית.
בתוך פסקה, טקסט בין `**…**` יודגש.
פריט ב-paragraphs שהוא `{"items": [...]}` הופך לרשימה מוזחת.
לתאריך העברי: `https://www.hebcal.com/converter?cfg=json&gy=YYYY&gm=M&gd=D&g2h=1`.
מכתבים עצמם לא נשמרים בריפו, כי הוא ציבורי.
