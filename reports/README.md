# דו״ח יומי ומצגת שבועית

## איך זה עובד
1. **כל יום (א׳–ה׳), בסוף היום** – פותחים סשן ומדביקים רשימה של מה שקרה. בכל צורה: נקודות, משפטים, הקלדה קולית.
2. Claude שואל רק אם משהו באמת לא ברור, שומר את היום ב-`daily/`, ומכין **טיוטה ב-Gmail** למנהל.
3. נכנסים לטיוטה, עוברים 10 שניות, לוחצים **שלח**.
4. **ביום א׳** – כותבים "מצגת שבועית" ומקבלים מצגת ב-Canva על השבוע הקודם.

## פקודות
- רשימה כלשהי ← דו״ח יומי (בדיוק בניסוח שלך)
- `תקן: …` ← תיקון לדו״ח של היום
- `מצגת שבועית` ← מצגת Canva
- `מה פתוח?` ← כל המשימות הפתוחות

## קבצים
| קובץ | מה זה |
|---|---|
| `PROCESS.md` | ההוראות המלאות ל-Claude (הפרומפט הקבוע) |
| `config.md` | שם, מנהל, מייל, פרויקטים – **למלא לפני השימוש הראשון** |
| `templates/` | תבניות: רשומה יומית, מייל, מבנה מצגת |
| `daily/` | רשומה לכל יום – מקור הנתונים למצגת |
| `weekly/` | סיכום לכל שבוע |

> ⚠️ הריפו ציבורי: כל מה שנשמר כאן גלוי לכולם. אל תכניסו מידע רגיש (שכר, לקוחות, מחירים, בעיות כוח אדם).
