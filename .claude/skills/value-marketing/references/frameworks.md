# מסגרות שימושיות (מקוצר מהמקורות)

## פירמידה הפוכה (stakeholder-communication)
כותרת במשפט אחד ← "אז מה" והבקשה בפסקה אחת ← סטטוס והתקדמות ← סיכונים ובקשות ← פירוט ונספח.
חותכים מלמטה. אם העדכון מקוצר, הראש שורד.

## חמש השאלות לפני כל עדכון
1. מי הקהל בדיוק (המנהל? המייסד? מה מעניין כל אחד?)
2. מה הכותרת (אם יקראו משפט אחד)
3. מה ה"אז מה"
4. מה מבקשים: לידיעה / החלטה / הסלמה / בקשה / חגיגה
5. באיזה פורמט

## מודל הפעולה האנושית (copywriting)
אי נוחות (המצב לפני) ← חזון (מה אפשרי עכשיו) ← הדרך (מה נעשה).
מבחן "עכשיו אפשר": אחרי העדכון, מה הארגון יכול לעשות שלא יכול היה קודם?

## עקרונות פסיכולוגיים רלוונטיים (marketing-psychology)
- **Peak-End:** זוכרים את השיא ואת הסוף. לפתוח בהישג, לסיים בבקשה או בשורת ערך.
- **Curse of Knowledge:** מה שברור לאדם לא ברור להנהלה. לתרגם מונחים טכניים לתוצאה.
- **Goal-Gradient:** להראות התקדמות לקראת יעד ("4 מתוך 6 שלבים") מגביר מחויבות ותמיכה.
- **Anchoring / Contrast:** להשוות לנקודת ייחוס: לפני ואחרי, שבוע שעבר מול השבוע, עלות ספק חיצוני מול עשייה פנימית (רק עם נתונים אמיתיים).
- **Zeigarnik:** דברים פתוחים נזכרים. לסגור לולאות במפורש: "נסגר" עם תאריך.
- **Pratfall:** הודאה בקושי קטן מגבירה אמינות. לא להסתיר דחיות.
- **Mere Exposure / Rule of 7:** עקביות. אותו מבנה, אותם 3 מספרים, כל שבוע, בונה תדמית.
- **Social Proof / Authority:** ציטוט או תגובה של גורם חיצוני (ח״כ, שותף, תורם) שווה יותר מכל תיאור עצמי, כשהוא אמיתי ונאמר.

- "{מספר} {יחידות} ב{נושא}" (למשל "12 פעילים חדשים בשבוע אחד")
- "{משהו} עלה לאוויר / נסגר / הוגש"
- "מ{מצב קודם} ל{מצב חדש}"
