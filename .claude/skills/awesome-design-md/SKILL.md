# awesome-design-md

Source: github.com/VoltAgent/awesome-design-md (curated DESIGN.md collection). This skill is only the
collection plus this index; it has no scripts.

## How to use

1. List the brands: `ls design-md/` (next to this file). Each brand has its own folder.
2. Read `design-md/<brand>/DESIGN.md` for the one the user named, or the closest match to the look they want.
3. Use it as building blocks (palette, type scale, spacing, component rules), not as a copy of the site.
   Do not reuse the brand's logo, name or trademarked assets in the user's work.
4. If the user's own brand already has a visual language (for example the כוח התערבות navy-and-yellow
   style), that language wins; borrow only structure (spacing, hierarchy) from a DESIGN.md.
