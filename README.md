# כח התערבות – התוכנית לכנסת

אתר סטטי (HTML/CSS/JS, בלי בנייה) שמציג את חברי הדירקטוריון, המטרות של כל אחד ולוח השלבים והזמנים.

## עריכת תוכן
כל התוכן נמצא בקובץ אחד: **`data.js`** – שמות, תפקידים, מטרות, שלבים, מועדים וסטטוס
(`done` = הושלם, `active` = בביצוע, `planned` = מתוכנן).

תמונות: שימו קבצים בתיקייה `assets/directors/` (מומלץ לחתוך לגודל 660x1000 – יחס 2:3)
ועדכנו את השדה `photo`, למשל `"assets/directors/odelia.jpg"`. בלי תמונה יוצגו ראשי תיבות.

קישור ישיר לחבר דירקטוריון: `.../#odelia` (לפי השדה `id`).

## צפייה מקומית
```
python3 -m http.server 8000
```
ואז לפתוח http://localhost:8000

## פרסום ב-GitHub Pages
Settings → Pages → Source: *Deploy from a branch* → בוחרים את הענף ואת התיקייה `/ (root)` → Save.
