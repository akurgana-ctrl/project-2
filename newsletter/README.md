# הניוזלטר של כח התערבות: מדריך למי שממשיך

התיקייה הזו מכילה את כל מה שצריך כדי להוציא את הניוזלטר השבועי: הגיליונות, התמונות, הכללים, וסקריפט שבונה את ה-HTML למיילצ'ימפ.

## הדרך הקלה: עם Claude Code

פותחים את התיקייה (או את הריפו כולו) ב-Claude Code, וכותבים לו למשל:
> "בוא נעשה את גיליון 5. תעבור על הדוחות היומיים והיומן של השבוע ותציע נושאים."

Claude יקרא לבד את הסקיל `koach-newsletter`, שנמצא ב-`.claude/skills/koach-newsletter/SKILL.md`, ואת הכללים שב-`STYLE.md`, ויעבוד לפיהם: יציע נושאים, יכתוב את הגיליון, יבנה אותו, ויכין עמוד העתקה בלחיצת כפתור.

## הדרך הידנית

צריך: Python 3 עם Pillow, ו-Node עם Playwright (רק לתמונות ממותגות ולתצוגת טלפון).

1. מעתיקים את הגיליון האחרון, למשל `issue-04.html`, ל-`issue-05.html`.
2. מחליפים את התוכן. בראש הקובץ מעדכנים את השורות `כותרת:` ו`נושא:`, ובפס הכחול את מספר הגיליון ואת התאריך.
3. תמונות שמים ב-`images/`, קבצים להורדה ב-`docs/`, וקישורים חדשים מוסיפים ב-`tracking/links.py`.
4. בונים: `python3 publish.py issue-05.html`
5. דוחפים לגיטהאב, כי התמונות נטענות משם.
6. פותחים את `out/issue-05/mailchimp-copy.html` ולוחצים "העתקת ה-HTML למיילצ'ימפ".
7. במיילצ'ימפ: Create ← Email ← Code your own ← Paste in code. את שורת הנושא מדביקים ב-Subject line.

## מה חשוב לדעת

- **כל הכללים** (מבנה, ניסוח, צבעים, מה לא כותבים) נמצאים ב-`STYLE.md`. כדאי לקרוא אותו פעם אחת.
- **תמונות:** נטענות מהכתובת שבראש `publish.py`. אם מעבירים את התיקייה לריפו אחר, כותבים את הכתובת החדשה בקובץ `assets-url.txt`.
- **תמונה במסגרת המותג:** `python3 tools/frame_photo.py תמונה.jpg images/תוצאה.jpg "כותרת" "שורה משנית"`.
- **לאתר:** `python3 site_copy.py issue-01.html issue-02.html ...` בונה עמוד עם כפתור העתקה לכל גיליון.
- **נתונים:** מיילצ'ימפ סופר פתיחות ולחיצות לבד, בדוח של כל קמפיין.
