# מעקב לחיצות בניוזלטר

כל כפתור בניוזלטר עובר דרך סקריפט קטן בחשבון הגוגל שלך. הסקריפט רושם את הלחיצה בגיליון "כח התערבות · מעקב לחיצות ניוזלטר" ומעביר את הקורא מיד ליעד. עמוד המעקב מציג את הספירה מתוך אותו גיליון.

## הפעלה (פעם אחת, כ-5 דקות)

1. נכנסים ל-https://script.google.com עם akurgana@gmail.com ולוחצים **פרויקט חדש**.
2. מדביקים את תוכן `Code.gs` במקום הקוד שיש שם.
3. **קובץ חדש ← HTML**, קוראים לו `Redirect` (בדיוק כך), ומדביקים את תוכן `Redirect.html`.
4. **פריסה ← פריסה חדשה ← סוג: אפליקציית אינטרנט**:
   - הפעלה בתור: **אני**
   - למי יש גישה: **כל אחד**
5. גוגל יבקש הרשאה לגיליון. מאשרים (אם מופיע "האפליקציה לא אומתה": מתקדם ← מעבר לפרויקט).
6. מעתיקים את כתובת אפליקציית האינטרנט (מסתיימת ב-`/exec`) ושולחים אותה ל-Claude. היא נכנסת ל-`deploy-url.txt`, ומאותו רגע כל הכפתורים בגיליון עוברים דרך המעקב.

עד שהכתובת נכנסת, הכפתורים מובילים ישר ליעד, כך שהגיליון עובד בכל מקרה.

## כפתור חדש בגיליון הבא

מוסיפים שורה בלשונית `links` (מזהה, שם, יעד, מספר גיליון), את אותו מזהה ויעד ב-`links.py`, ובקובץ הגיליון כותבים `href="{{T:<מזהה>}}"`.

## מה נספר ומה לא

- כל לחיצה על כפתור, כולל כמה לחיצות של אותו אדם.
- פתיחות של המייל לא נספרות: בשליחה מג'ימייל אין לזה דרך אמינה.
